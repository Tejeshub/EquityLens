# Contribution Guide

Thanks for considering a contribution to EquityLens.

## How to Contribute

1. Fork the repository and create a feature branch.
2. Keep changes focused and scoped to a single goal.
3. Follow existing patterns in backend agents and frontend components.
4. Update tests if you change API contracts or data models.
5. Ensure lint and tests pass before submitting a PR.

## Development Notes

- Backend entrypoint: `backend/main.py`
- Frontend app: `frontend/insight-navigator`
- API contracts live in `backend/models.py`

## Pull Request Checklist

- Clear summary and rationale
- Screenshots for UI changes
- Tests updated (if applicable)
- No secrets or API keys committed
